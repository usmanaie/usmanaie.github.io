## Before flipping DNS

1. Set repository variables: `SITE_URL`, `FIREBASE_PROJECT_ID`, `GCP_WORKLOAD_IDENTITY_PROVIDER`, `GCP_SERVICE_ACCOUNT`.
2. Run the CI workflow with `update_baselines: true`, review the screenshots, and commit `tests/visual/__screenshots__/linux/`.
3. Merge to `main` and confirm the production deploy job.
4. In Firebase Hosting, add the apex domain plus `www` as a redirect to the apex; wait for the certificate.
5. Check headers on the live URL (securityheaders.com, Mozilla Observatory); submit the HSTS preload when confident.
6. Run WebPageTest (Moto G class, 4G) and check the Search Console Core Web Vitals report after traffic arrives.
7. Set up the uptime check (see README → Operations).
