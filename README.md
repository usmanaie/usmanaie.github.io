# Usman Aslam — Portfolio

Personal portfolio of Usman Aslam, Lead AI Engineer and Google Cloud Certified Developer.
A premium, glassmorphism-style site showcasing projects, experience and certifications.

## Development setup

### Claude Code design skills

The UI/UX Pro Max skills live in `.claude/skills/`, which is git-ignored. Reinstall them on each machine
(requires Node.js and Python 3):

```bash
npm install -g ui-ux-pro-max-cli
uipro init --ai claude
```

Run `uipro update` to refresh them later. Source: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
